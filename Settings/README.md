# Settings

Один класс: `ProjectSettings.cs` — параметры запуска приложения, не самого
мира (не путать с Models/`WorldSettings.cs` — те определяют поведение
симуляции: возрастные пороги, шансы событий и т.п., и сохраняются вместе
с миром; `ProjectSettings` существуют только на время одного запуска и не
сериализуются).

`Apply(args, output)` разбирает аргументы командной строки (--years,
--settlements, --population, --seed, --quiet, --help), проверяет их
(отрицательные/нулевые значения ловятся здесь, а не глубоко внутри
генерации, где причина ошибки уже не видна) и возвращает false, если
запуск продолжать не нужно — молча проглатывать опечатку в имени
параметра нельзя, иначе пользователь решит, что настройка применилась.

Значения по умолчанию — те, что раньше были зашиты в код: 30 жителей,
100 лет, 3 поселения, случайное зерно.
