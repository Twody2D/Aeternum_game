# Export

Отдельный, более плоский снимок мира — для клиента-отрисовщика (задуманного
на Godot), не для продолжения симуляции. Не путать с ../Save/README.md: то
сохранение обязано следовать за моделью и хранить всё, вплоть до полной
родословной каждого когда-либо жившего; этот снимок — за тем, что клиент
показывает, и хранит только уже готовые к показу числа и подписи, без
обходов графа объектов на стороне отрисовки.

  - `WorldSnapshot.cs` — сами DTO снимка (расселение, события таймлайна,
    государства и т.п. — уже развёрнутые, без Id-ссылок на объекты, которые
    отрисовке пришлось бы резолвить самой).
  - `SnapshotExporter.cs` — сборка снимка из World. Как и `SaveSystem`, работает
    со строкой: `Export(world, path)` — тонкая обёртка поверх `Serialize(world)`
    с записью в файл; консоль сама решает писать на диск, будущему Godot-
    клиенту достаточно того же JSON, полученного любым путём.

`Program.cs` вызывает экспорт отдельно от сохранения, в конце каждого запуска.
