# Generators

Фабрики, которые собирают стартовый контент мира из шаблонов, загруженных
через ../Data/`ContentData.cs`. Отличие от Systems: генератор создаёт новый
объект и отдаёт его вызывающему коду, а не изменяет мир сам.

  - `CharacterGenerator.cs` — случайный житель: имя/фамилия из Data/`Names.json`,
    `Create()` — "взрослый с историей" для стартового населения (возраст,
    профессия, стаж, черты характера), `CreateNewborn()` — младенец для
    `BirthSystem`/`BastardSystem`.
  - `SettlementGenerator.cs` — поселения: как стартовые (раскиданы случайно по
    карте), так и колонии (см. `ColonizationSystem`) — колонисты осматривают
    несколько мест рядом с родителем и оседают на самом плодородном.
    Имена — Data/`Settlements.json`.
  - `CultureGenerator.cs` — культуры: имя плюс предпочитаемая категория
    профессий. Шаблоны — Data/`Cultures.json`.
  - `ReligionGenerator.cs` — религии, по образцу `CultureGenerator`, из
    Data/`Religions.json`; также умеет `CreateSchism` — новую веру при расколе
    (см. `SchismSystem`).
  - `LanguageGenerator.cs` — языки: их меньше, чем культур, — несколько
    родственных народов говорят на одном наречии, поэтому языковая граница
    не совпадает с культурной.
